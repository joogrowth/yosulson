# 식자재 시세 월간보고 지침

목표: API로 시세를 모아 **대시보드**를 만들고, 그 화면을 웹으로 보여 준다.
PDF는 드라이브에 올리지 않는다. 필요하면 사용자가 대시보드에서 **PDF로 저장**한다.

코드 정본: https://github.com/joogrowth/yosulson/tree/main/식자재

---

## 한 줄 흐름

1. 시세 수집 (API) → `식자재/시세/data/latest.json`
2. 대시보드 생성 → `식자재/식재료시세분석/index.html` (GitHub에 반영)
3. 웹으로 확인 → https://joogrowth.github.io/yosulson/식자재/식재료시세분석/
4. PDF가 필요하면 사용자가 그 화면에서 **PDF로 저장** (드라이브에 따로 안 올림)

---

## 명령

```
cd 식자재/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
python3 scripts/build_dashboard.py --month YYYY-MM --as-of YYYY-MM-DD
```

## 숫자 규칙

- KAMIS 소매가 기본
- 소매 없는 품목만 가락 도매 보완 (소매 있는 품목에 도매 덮지 않음)
- 생선 등은 노량진 경락
- 직전 출하기 가격을 당월로 복사하지 않음
- 비교: 전월 한 달 평균 vs 당월 구간 평균

인증: `KAMIS_CERT_KEY`, `KAMIS_CERT_ID` (문서·GitHub에 키 값 금지)
수집은 로컬(맥) 권장.

## 어디에 무엇을

| 곳 | 내용 |
|----|------|
| GitHub `식자재/` | 스크립트, 대시보드 HTML, 지침, 기억 |
