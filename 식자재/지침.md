# 식자재 시세 월간보고 지침

다른 AI가 Cursor에게 하듯이, 식자재 월간 시세 보고를 같은 순서로 만들고 드라이브에 공유하기 위한 지침이다.

코드 정본: https://github.com/joogrowth/yosulson/tree/main/식자재

이 지침과 코드가 다르면 **코드가 우선**이다.
드라이브의 예전 식자재 지침 숫자는 현재 규칙으로 쓰지 않는다.

---

## 1. 역할 나누기

| 어디에 | 무엇을 |
|--------|--------|
| GitHub `식자재/` | 수집 스크립트, 대시보드 HTML, 지침, 기억 |
| 드라이브 `요술손/식자재` | 완성 PDF, 이번 달 메모, 지침 사본 |

- PDF·시세 JSON 원본은 GitHub에 올리지 않는다. (`시세/data/latest.json` 포함)
- 보고서는 원가 장부가 아니다. 구매 대비·대체 판단을 위한 **시장 시세 동향**이다.

드라이브 폴더: https://drive.google.com/drive/folders/1NzS7cW80M5_j403etnZB9cg6rvyrepF9

파일 이름 예: `요술손_시세월간보고_2026-11.pdf`

---

## 2. 숫자를 모을 때

1. **KAMIS 소매**가 기본이다.
2. 소매 조사가 비는 품목만 **가락 도매**로 보완한다.  
   소매가 있는 품목에 도매가를 덮어쓰지 않는다. (출하 단위가 다름)
3. 생선 등은 **노량진 경락**을 함께 본다.
4. 직전 출하기 가격을 당월 가격으로 복사하지 않는다.
5. 비교는 **전월 한 달 평균**과 **당월 구간 평균**이다.

수집은 로컬(맥 등)에서 돌리는 것을 권장한다. KAMIS는 일부 클라우드 IP를 막을 수 있다.  
인증: 환경변수 `KAMIS_CERT_KEY`, `KAMIS_CERT_ID` (GitHub·문서에 키 값을 쓰지 않는다.)

---

## 3. 한 달 보고 만들기 순서

사용자가 “YYYY년 M월 시세 월간보고 만들어줘”라고 하면 아래를 따른다.

### A. 시세 수집

```
cd 식자재/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
```

- `--days 45`는 전월 비교용 기본값이다.
- 결과: `식자재/시세/data/latest.json` (저장소에 커밋하지 않는다)

### B. 대시보드(월간 보고 화면) 생성

```
cd 식자재/시세
python3 scripts/build_dashboard.py --month YYYY-MM --as-of YYYY-MM-DD
```

- 출력: `식자재/식재료시세분석/index.html`
- `식자재/시세/월간보고/` 는 위 화면으로 보내는 입구다.
- 다음 달 제철 화면: `식자재/시세/전망/index.html` (빌드 시 함께 갱신될 수 있다)

### C. PDF로 저장

1. `식자재/식재료시세분석/index.html` 을 연다.
2. 오른쪽 위 **PDF로 저장**을 누른다.
3. 인쇄 창에서 **머리글 및 바닥글**을 끈다.
4. PDF로 저장한다.
5. 파일명을 `요술손_시세월간보고_YYYY-MM.pdf` 형태로 맞춘다.

### D. 드라이브에 공유

완성 PDF(와 필요하면 이번 달 메모)를 드라이브 `요술손/식자재`에 올린다.  
GitHub에는 PDF를 올리지 않는다.

코드·지침·기억을 고쳤으면 GitHub에 올리고 합친다. 사용자가 「저장해줘」라고 하면 합치기까지 한다.

## 4. 화면 주소 (저장소 안)

- 월간 보고: `식자재/식재료시세분석/index.html`
- 시세 조회·데이터 관리: `식자재/시세/index.html`
- 다음 달 제철: `식자재/시세/전망/index.html`
- 수집 스크립트: `식자재/시세/scripts/`

---

## 5. 작업 규칙

1. 작업을 시작하기 전에 `식자재/기억.md`를 읽는다.
2. 추측으로 출처 규칙(소매/도매 덮어쓰기 등)을 바꾸지 않는다.
3. API 키·비밀번호는 GitHub·지침·기억에 넣지 않는다.
4. `latest.json` 및 수집 산출물은 GitHub에 커밋하지 않는다.
5. 근퇴·배송·급여와 자동 연결하는 원스톱은 만들지 않는다.
6. 중요한 운영 결정은 `식자재/기억.md` 최근 결정에 날짜와 한 줄로 남긴다.
7. 드라이브 지침 사본과 GitHub 지침이 다르면 **GitHub를 고친 뒤** 드라이브를 맞춘다.

---

## 6. 사용자가 말할 때

- “11월 시세 월간보고 만들어줘” → 위 3절 순서대로 수집·빌드·PDF·드라이브 안내
- “지침만 맞춰줘” → GitHub `식자재/지침.md`와 드라이브 지침만 동기화
- “저장해줘” → GitHub에 올리고 합치기까지
