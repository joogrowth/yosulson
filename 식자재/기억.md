# 식자재 기억

먼저 이 파일과 `지침.md`를 읽는다.

## 방식

- API로 시세 수집 → 대시보드(`식재료시세분석/index.html`) 갱신
- **매달 보는 곳** = 웹 대시보드 주소 (PDF를 드라이브에 따로 올리지 않음)
- PDF가 필요하면 사용자가 대시보드에서 **PDF로 저장**
- 드라이브에 HTML·PDF·안내 문서를 쌓지 않음

## 주소

- 지침: `식자재/지침.md`
- 대시보드(웹): https://joogrowth.github.io/yosulson/식자재/식재료시세분석/
- 대시보드(코드): `식자재/식재료시세분석/index.html`
- 수집: `식자재/시세/scripts/fetch_month.py`, `build_dashboard.py`
- 드라이브 식자재 루트: https://drive.google.com/drive/folders/1NzS7cW80M5_j403etnZB9cg6rvyrepF9

## 명령

```
cd 식자재/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
python3 scripts/build_dashboard.py --month YYYY-MM --as-of YYYY-MM-DD
```

그다음 웹 대시보드 주소로 확인. PDF는 사용자가 필요할 때만 저장.
