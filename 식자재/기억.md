# 식자재 기억

먼저 이 파일과 `지침.md`를 읽는다.  
GitHub와 드라이브 기억이 다르면 **GitHub가 정본**이고, 드라이브를 맞춘다.

## 한 줄로

매달 시세를 모아 **월별 웹 대시보드**를 만들고, 주소를 나눠 **계속 쌓는다.**  
드라이브에 PDF·HTML을 올리지 않는다. PDF는 사용자가 그달 화면에서 저장한다.

## 방식 (고정)

1. API로 시세 수집 → `식자재/시세/data/latest.json`
2. 그달 대시보드 생성 → `식자재/식재료시세분석/YYYY-MM/index.html`
3. 월 목록도 갱신 → `식자재/식재료시세분석/index.html`
4. GitHub에 반영 → 웹으로 확인
5. **지난 달 폴더는 지우지 않는다.** 쌓이다가 사용자가 삭제 요청하면 그때 해당 `YYYY-MM`만 지운다.

하지 않는 것:
- 한 주소만 덮어쓰기 (최신만 남기기) → 안 함. **달마다 주소 분리**
- 드라이브에 월간 PDF·HTML·안내 문서 쌓기 → 안 함

## 주소

- 메인: https://joogrowth.github.io/yosulson/
- 월 목록(쌓인 달 전부): https://joogrowth.github.io/yosulson/식자재/식재료시세분석/
- 예) 2026-11: https://joogrowth.github.io/yosulson/식자재/식재료시세분석/2026-11/
- 코드: `식자재/식재료시세분석/YYYY-MM/index.html`
- 지침: `식자재/지침.md`
- API: `식자재/API.md`
- 수집 스크립트: `식자재/시세/scripts/fetch_month.py`, `build_dashboard.py`

링크를 줄 때는 **메인**도 항상 같이 준다.  
모바일·데스크톱 모두 위 웹 주소로 보고·요청·확인한다.

## 명령

```
cd 식자재/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
python3 scripts/build_dashboard.py --month YYYY-MM --as-of YYYY-MM-DD
```

→ `YYYY-MM` 대시보드 + 월 목록 갱신. 이전 달 `YYYY-MM` 폴더는 그대로 둔다.

인증: `KAMIS_CERT_KEY`, `KAMIS_CERT_ID` (값은 GitHub·채팅·기억에 쓰지 않음. 비공개 시크릿·실행 환경만)
