# 식자재 기억

이 파일을 먼저 읽고 이어서 작업한다. 중요한 결정·운영 방식은 여기에 짧게 남긴다.

## 지금 쓰는 방식

- 월간 시세 분석은 대시보드로 만들고, 사람은 PDF로 저장한다.
- 수집·대시보드 코드는 GitHub `식자재/` 에 둔다.
- 실시간/월간 자료는 스크립트로 모으고, 화면으로 보여 준다.

## 꼭 지킬 것

- 드라이브의 예전 식자재 지침 숫자는 현재 규칙으로 쓰지 않는다.
- `식자재/시세/data/latest.json` 은 저장소에 올리지 않는다.
- 근퇴·배송·급여와 자동 연결하는 원스톱은 만들지 않는다.

## 주소

- 월간 보고: `식자재/식재료시세분석/index.html`
- 시세 조회: `식자재/시세/index.html`
- 다음 달 제철: `식자재/시세/전망/index.html`
- 수집 스크립트: `식자재/시세/scripts/`
- 드라이브 식자재 폴더: https://drive.google.com/drive/folders/1NzS7cW80M5_j403etnZB9cg6rvyrepF9

## 월간 다시 만들기

```
cd 식자재/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
python3 scripts/build_dashboard.py --month YYYY-MM --as-of YYYY-MM-DD
```
