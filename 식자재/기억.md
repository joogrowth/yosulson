# 식자재 기억

먼저 이 파일과 `지침.md`를 읽는다.

## 방식

- API로 시세 수집 → 대시보드(`식재료시세분석/index.html`) → **PDF로 저장**한 파일이 최종본
- 최종본 형태는 대시보드 PDF다. 문서 요약·깨진 임시 HTML은 최종이 아니다.
- 드라이브 월별 폴더에는 **2개만**: `요술손_시세월간보고_YYYY-MM.pdf` + `대시보드.html`
- 대시보드 화면(웹): https://joogrowth.github.io/yosulson/식자재/식재료시세분석/

## 주소

- 지침: `식자재/지침.md`
- 대시보드: `식자재/식재료시세분석/index.html`
- 수집: `식자재/시세/scripts/fetch_month.py`, `build_dashboard.py`
- 드라이브: https://drive.google.com/drive/folders/1NzS7cW80M5_j403etnZB9cg6rvyrepF9
- 2026-11 폴더: https://drive.google.com/drive/folders/1Iw2lKKP6b6290SAn0BTSmURehHnifYmW

## 명령

```
cd 식자재/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
python3 scripts/build_dashboard.py --month YYYY-MM --as-of YYYY-MM-DD
```
