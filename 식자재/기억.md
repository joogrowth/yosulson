# 식자재 기억

먼저 이 파일과 `지침.md`를 읽는다.

## 방식

- API로 시세 수집 → 달별 대시보드(`식재료시세분석/YYYY-MM/index.html`) 생성
- **매달 보는 곳** = 웹 주소 (달마다 주소가 다름). 쌓이면 사용자가 삭제 요청
- 목록: https://joogrowth.github.io/yosulson/식자재/식재료시세분석/
- PDF는 드라이브에 올리지 않음. 필요하면 사용자가 그달 화면에서 **PDF로 저장**

## 주소

- 지침: `식자재/지침.md`
- 월 목록(웹): https://joogrowth.github.io/yosulson/식자재/식재료시세분석/
- 2026-11: https://joogrowth.github.io/yosulson/식자재/식재료시세분석/2026-11/
- 코드: `식자재/식재료시세분석/YYYY-MM/index.html`
- 수집: `식자재/시세/scripts/fetch_month.py`, `build_dashboard.py`

## 명령

```
cd 식자재/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
python3 scripts/build_dashboard.py --month YYYY-MM --as-of YYYY-MM-DD
```

→ `식재료시세분석/YYYY-MM/index.html` + 월 목록 갱신
