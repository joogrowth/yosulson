# 배송 기억

이 파일을 먼저 읽고 이어서 작업한다. 중요한 결정·운영 방식은 여기에 짧게 남긴다.

## 지금 쓰는 방식

- 사람은 **배송견적 화면**(`배송/index.html`)에 로그인해서 견적문의·제원·최종저장을 한다. (대표님은 견적문의, 팀장님은 제원)
- 화면 ↔ 구글시트 다리는 **Apps Script 웹앱**(`배송/apps-script/`)이다.
- 데이터는 구글시트 **배송견적** 하나에만 쌓인다. 사본·시험용 시트를 새로 만들지 않는다.
- 관리자 아이디는 `admin` 고정. 비밀번호는 화면의 「관리자 등록」에서 직접 정한다. GitHub·문서에 비밀번호를 쓰지 않는다.
- 대표님은 화면의 「새 계정 만들기」로 등록한다. (아직 미등록이면 나중에 한다.)
- 채팅으로 견적만 물어볼 때의 계산·복붙 틀은 `지침.md`를 따른다. 시트 저장은 화면·웹앱이 한다.

## 꼭 지킬 것

- **수고비는 넣지 않는다.** 구간 수고비·추가 수고비(적재, 외곽, 세팅 등) 모두 금지.
- 견적 결과 문장·비밀번호는 GitHub에 올리지 않는다. 코드·지침·기억만 GitHub다.
- 예전 시트 **배송견적 기록**(휴지통)은 쓰지 않는다. 주소를 다시 살리지 않는다.
- 웹앱 `/exec` 주소를 바꿀 때 새 배포를 함부로 만들지 않는다. 기존 배포를 새 버전으로 업데이트한다.
- 근퇴 Apps Script·근퇴/급여/식자재 폴더는 배송 작업에서 건드리지 않는다.
