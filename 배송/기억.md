# 배송 기억

이 파일을 먼저 읽고 이어서 작업한다. 중요한 결정·운영 방식은 여기에 짧게 남긴다.

## 지금 쓰는 방식

- 사람은 계산기 화면을 직접 쓰지 않는다.
- 채팅에 제원을 주면 AI가 계산하고 카톡 복붙용 문장으로 답한다.
- 복붙용 견적을 만든 직후 **배송견적 기록** 시트에 자동으로 한 행 넣는다.
- “기록하지 마”라고 하면 그 건만 시트에 넣지 않는다.
- 시트는 아래 최종본 하나만 쓴다. 사본·시험용 시트를 새로 만들지 않는다.

## 꼭 지킬 것

- **수고비는 넣지 않는다.** 구간 수고비·추가 수고비(적재, 외곽, 세팅 등) 모두 금지. `수고비합계`는 항상 0.
- 견적 결과 문장은 GitHub에 올리지 않는다. 코드·지침·기억만 GitHub다.
- 드라이브의 예전 `배송견적`·`배송견적 규정` 문서는 현재 규칙이 아니다.
