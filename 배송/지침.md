# 배송견적 지침

다른 AI가 Cursor에게 하듯이 배송·배송세팅·출장 견적을 바로 계산하고, 카톡에 붙여 넣을 문장으로 답하기 위한 지침이다.

사람은 계산기 화면을 직접 쓰지 않는다. 제원을 주면 AI가 계산하고 복붙용 텍스트를 만든다.

계산 코드 정본: https://github.com/joogrowth/yosulson/blob/main/배송/index.html

이 지침의 숫자·식은 위 코드와 같게 맞춘다. 코드가 바뀌면 코드가 우선이다.

구간 수고비는 쓰지 않는다. km 구간표로 수고비를 넣지 않는다.

---

## 1. 받을 제원

가능하면 아래를 받는다. 비어 있으면 물어보거나, 있는 값만으로 계산하고 빠진 칸을 표시한다.

- 종류: `배송` / `배송세팅` / `출장` 중 하나
- 이름(담당·고객)
- 소속행사명(있으면)
- 날짜
- 장소(주소)
- 연락처(있으면, 여러 줄 가능)
- 품목(있으면)
- 출발 시각, 도착 시각, 행사 시간(있으면)
- 갈 때 분, 올 때 분 (왕복 이동 시간, 분)
- 편도 km
- 편도 연료비(원)
- 통행료 편도(있으면)
- 주차비(있으면)
- 추가 수고비 항목(있으면: 이름과 금액. 예: 적재, 외곽, 세팅. 사용자가 말한 것만 넣는다)

사용자가 "지난 실측"을 말하면, 같은 장소의 이전 확정 제원(거리·연료·통행료·시간)을 우선한다.

---

## 2. 계산

모든 금액은 원 단위. 표시는 천 단위 콤마.

### 기본값

- `왕복km` = 편도km × 2
- `총분` = 갈때분 + 올때분
- `총시간문자` = `N시간` 또는 `N시간 M분`
- 시급 세 가지: 11000, 12000, 13000

### 인건비

각 시급마다

`인건비 = round(시급 × 총분 / 60)`

세 값을 ` / ` 로 이어 쓴다.

### 수고비

구간 수고비는 없다.

`수고비합계` = 사용자가 말한 추가 수고비 합만

추가 항목이 없으면 수고비는 0이고, 복붙 문장에서 수고비 줄을 빼도 된다.

사용자가 빼 달라고 한 항목은 넣지 않는다.

### 차량 운영비

`차량운영비 = round(왕복km × 222)`

유류비와 별개다.

### 유류비

`유류비 = ceil((편도연료비 × 2) / 100) × 100`  (100원 단위 올림)

### 통행료·주차비

- 통행료가 있으면 `통행료 = 편도통행료 × 2`
- 주차비가 있으면 그 금액을 그대로 쓴다. 합계에 포함하고, 필요하면 "주차비 제외" 합계도 따로 적는다.

### 합계

`기본 = 차량운영비 + 유류비 + 수고비합계 + 통행료`

각 시급마다

`합계 = 기본 + 인건비 + (주차비 있으면 주차비)`

주차비가 있으면

`주차비제외 = 기본 + 인건비`

## 3. 복붙용 답 형식

카톡에 바로 붙여 넣을 수 있게, 아래 형식으로만 답한다. 설명 문단을 앞에 길게 쓰지 않는다.

```text
[종류] 이름 / 소속행사명
일시: YY.MM.DD(요일) / 출발: … / 도착: … / 행사시간: …
장소: …
연락처: …
품목: …

•배송 인건비 A원 / B원 / C원
(시급 11,000원 × 왕복 N시간… / 시급 12,000원 × … / 시급 13,000원 × …)
•배송 수고비 …원   ← 추가 수고비가 있을 때만
(추가항목 …원 + …)
•차량 운영비 …원
(왕복 …km × 222원/km / 감가상각·소모품·유지비 포함 / 유류비 제외)
•유류비 …원
(편도 …원 × 왕복 2 = …원 → 100단위 올림)
•통행료 …원   ← 있을 때만
(편도 …원 × 왕복 2)
•주차비 …원   ← 있을 때만
(현장 실비 / 실정산 시 조정)

•합계 …원 / …원 / …원
(시급 11,000 / 12,000 / 13,000원 기준)
•주차비 제외 …원 / …원 / …원   ← 주차비가 있을 때만
```

없는 줄(연락처, 품목, 통행료, 주차비, 수고비 등)은 빼도 된다.

날짜 표시: `YY.MM.DD(요일)` 예: `26.11.12(수)`

---

## 4. 작업 규칙

1. 제원을 받으면 바로 위 형식으로 계산해 답한다.
2. 계산은 `배송/index.html` 과 같게 한다. 추측으로 요율을 바꾸지 않는다.
3. 구간 수고비는 쓰지 않는다.
4. 사용자가 빼 달라고 한 금액은 넣지 않는다.
5. 견적 결과 문장을 GitHub에 올리지 않는다. 코드만 GitHub다.
6. 드라이브의 예전 "규정" 문서나 빈 `배송견적` 문서 내용을 현재 규칙으로 쓰지 않는다.
7. 원스톱 연계(근퇴·급여와 자동 연결)는 설계하지 않는다. 견적만 한다.

## 5. 빠른 확인 예

편도 21km, 편도 연료비 4158원, 갈때 60분, 올때 60분, 추가 수고비·통행료·주차비 없음.

- 왕복 42km
- 인건비(2시간): 22000 / 24000 / 26000
- 차량운영비: round(42×222)=9324
- 유류비: ceil(8316/100)×100=8400
- 수고비: 없음
- 합계: 30724 / 32724 / 34724
