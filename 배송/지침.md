# 배송견적 지침

다른 AI가 Cursor에게 하듯이 배송·배송세팅·출장 견적을 바로 계산하고, 카톡에 붙여 넣을 문장으로 답하기 위한 지침이다.

사람은 계산기 화면을 직접 쓰지 않는다. 제원을 주면 AI가 계산하고 복붙용 텍스트를 만든다.

계산 금액 식은 https://github.com/joogrowth/yosulson/blob/main/배송/index.html 과 같게 한다. 코드의 요율이 바뀌면 코드가 우선이다.

복붙 문단의 틀은 이 문서 3항만 쓴다. `배송/index.html` 화면의 한 줄 일시 형식, `•배송 인건비`, 감가상각 문구는 쓰지 않는다.

**수고비는 넣지 않는다.** 구간 수고비·추가 수고비(적재, 외곽, 세팅 등) 모두 금지. `수고비합계`는 항상 0이다.

---

## 1. 받을 제원

가능하면 아래를 받는다. 비어 있으면 물어보거나, 있는 값만으로 계산하고 빠진 칸을 표시한다.

- 종류: `배송` / `배송세팅` / `출장` 중 하나
- 이름(담당·고객)
- 소속행사명(있으면)
- 날짜
- 장소(주소)
- 연락처(있으면, 여러 줄 가능)
- 품목(있으면)
- 출발 시각, 도착 시각, 행사 시간(있으면)
- 도착소요시간(분), 복귀소요시간(분) (왕복 이동 시간)
- 편도 km
- 편도 연료비(원)
- 통행료 편도(있으면)
- 주차비(있으면)

수고비 항목은 받지 않는다. 사용자가 말해도 견적·합계·시트에 넣지 않는다.

사용자가 "지난 실측"을 말하면, 같은 장소의 이전 확정 제원(거리·연료·통행료·시간)을 우선한다.

---

## 2. 계산

모든 금액은 원 단위. 표시는 천 단위 콤마.

### 기본값

- `왕복km` = 편도km × 2
- `총분` = 도착소요시간(분) + 복귀소요시간(분)
- `총시간문자` = `N시간` 또는 `N시간 M분`
- 시급 세 가지: 11000, 12000, 13000

### 인건비

각 시급마다

`인건비 = round(시급 × 총분 / 60)`

세 값을 ` / ` 로 이어 쓴다.

### 수고비

**넣지 않는다.** `수고비합계` = 0 고정.

복붙 문장에 수고비 줄을 만들지 않는다. 적재·외곽·세팅·기타 수고비 항목을 받지 않고, 말해도 무시한다.

### 차량 운영비

`차량운영비 = round(왕복km × 222)`

유류비와 별개다.

### 유류비

`유류비 = ceil((편도연료비 × 2) / 100) × 100`  (100원 단위 올림)

### 통행료·주차비

- 통행료가 있으면 `통행료 = 편도통행료 × 2`. 없으면 0원으로 적고 줄을 빼지 않는다.
- 주차비는 합계에 넣지 않는다. 문단 끝은 `주차비 별도`다. 금액이 있으면 `주차비 N원 (별도)`.

### 합계

`차량유지비 = 차량운영비 + 유류비 + 통행료`

각 시급마다

`합계 = 차량유지비 + 인건비`

주차비는 이 합계 밖이다. 주차비 제외 합계 열은 만들지 않는다.

## 3. 복붙용 답 형식

카톡에 바로 붙여 넣을 문단은 아래 틀만 쓴다. 줄 순서와 항목 이름을 바꾸지 않는다.

```text
[종류] 이름 / 행사명
일자: YY.MM.DD(요일)

출발: …
도착: …
행사시작: …

장소: …
담당자: 이름 (전화)
품목: …

--------------------------------

편도거리: Nkm (왕복 Nkm)
편도 연료비: …원
편도 통행료: …원
도착소요시간: … (N분)
복귀소요시간: … (N분)
총소요시간: N분 (…시간 …분)
•인건비 …원 / …원 / …원
(시급 11,000 / 12,000 / 13,000원 × N분)
•차량 운영비 …원
(왕복 Nkm × 222원/km, 유류비 제외)
•유류비 …원
(편도 …원 × 왕복 2)
•통행료 …원
•인건비 제외 차량유지비 …원
•합계 …원 / …원 / …원
(시급 11,000 / 12,000 / 13,000원 기준)
주차비 별도
```

날짜 표시: `YY.MM.DD(요일)` 예: `26.11.18(수)`

없는 연락처·품목만 빼도 된다. 거리, 연료비, 통행료, 소요시간, 인건비, 차량 운영비, 유류비, 통행료, 차량유지비, 합계, 주차비 별도는 남긴다.
수고비 줄은 만들지 않는다.

## 4. 배송견적 기록 시트에 자동 저장

복붙용 견적을 만든 뒤, 같은 내용의 숫자는 구글 시트 **배송견적 기록**에 한 행으로 바로 넣는다.
사람이 따로 “기록해줘”라고 말하지 않아도 넣는다.

시트는 이 파일 하나다. 사본이나 시험용 시트를 새로 만들지 않는다.

시트: https://docs.google.com/spreadsheets/d/1VaFa6dEGABF8aZzrIM9fjKfIqE_OckgFQvFMMhWUExQ/edit

첫 탭 이름은 `기록`으로 둔다. 상태 칸(A열)은 드롭다운이다. 고를 수 있는 값은 `확정`, `보류`, `취소`다. 새 행의 기본값은 `확정`이다.

`확정만` 탭은 상태가 `확정`인 행만 보여 준다. 없으면 새 탭을 만들고 A1에  
`=FILTER(기록!A:AD, 기록!A:A="확정")`  
를 넣는다. 나중에 확정 건만 볼 때는 그 탭을 연다.

행을 추가할 때도 상태 드롭다운과 `확정만` 탭을 유지한다. 행 높이는 한 줄로 둔다. 칸 너비는 헤더와 값이 잘리지 않게 둔다.

### 넣는 방법

1. 시트를 읽어 기존 행을 유지한다.
2. 맨 아래에 새 행을 추가한다. 상태 드롭다운, `확정만` 탭, 칸 너비는 남긴다.
3. 사용자에게 복붙 문장을 보여 준 뒤, 시트에 넣었다고 한 줄로 알린다. 시트 링크를 함께 준다.

### 열 순서 (헤더와 동일)

`상태,저장시각,날짜,이름,장소,종류,차종제원,소속행사명,연락처,품목,출발,도착,행사시간,도착소요시간(분),복귀소요시간(분),편도km,편도연료비,통행료편도,주차비,수고비합계,차량운영비,유류비,통행료왕복,인건비11000,인건비12000,인건비13000,합계11000,합계12000,합계13000,견적문구`

### 채우는 값

- `상태`: 드롭다운에서 `확정`, `보류`, `취소` 중 하나. 새 행은 `확정`
- `저장시각`: Asia/Seoul 기준 `YYYY-MM-DD HH:MM`
- 제원·계산 숫자: 해당 열에 숫자만 (콤마 없이)
- 없는 값: 빈 칸
- `수고비합계`: 항상 `0` (수고비 금지)
- `합계`: 주차비를 넣지 않은 금액
- `견적문구`: 받은 문구를 넣는다. 계산된 금액 문단은 넣지 않는다. 행 높이는 한 줄로 둔다.
- **수고비 관련 열·항목을 새로 만들지 않는다.** 기존 `수고비합계` 열은 0만 넣는다.
- **주차비 제외 합계 열은 없다. 만들지 않는다.**

사용자가 “기록하지 마”라고 하면 그 건만 시트에 넣지 않는다.

## 5. 작업 규칙

1. 제원을 받으면 3항 틀로 계산해 답한다. 틀을 바꾸지 않는다.
2. 금액 식은 `배송/index.html` 과 같게 한다. 추측으로 요율을 바꾸지 않는다. 문단 모양은 3항이 우선이다.
3. 수고비는 넣지 않는다. 구간·추가 모두 금지.
4. 사용자가 빼 달라고 한 금액은 넣지 않는다.
5. 복붙용 견적을 만든 직후 **배송견적 기록** 시트에 자동으로 한 행 넣는다. 견적문구에는 받은 문구를 넣는다. 상태는 `확정`으로 둔다. 시트를 새로 만들지 않는다. 칸 너비는 헤더가 보이게 유지한다.
6. 견적 결과 문장을 GitHub에 올리지 않는다. 코드·지침만 GitHub다.
7. 드라이브의 예전 "규정" 문서나 빈 `배송견적` 문서 내용을 현재 규칙으로 쓰지 않는다.
8. 원스톱 연계(근퇴·급여와 자동 연결)는 설계하지 않는다. 견적만 한다.

## 6. 빠른 확인 예

편도 21km, 편도 연료비 4158원, 도착소요시간 60분, 복귀소요시간 60분, 통행료·주차비 없음. 수고비 없음(항상).

- 왕복 42km
- 인건비(2시간): 22000 / 24000 / 26000
- 차량운영비: round(42×222)=9324
- 유류비: ceil(8316/100)×100=8400
- 차량유지비: 9324+8400=17724
- 합계: 39724 / 41724 / 43724
- 주차비 별도
