# 배송견적 지침

다른 AI가 Cursor에게 하듯이 배송·배송세팅·출장 견적을 바로 계산하고, 카톡에 붙여 넣을 문장으로 답하기 위한 지침이다.

사람은 계산기 화면을 직접 쓰지 않는다. 제원을 주면 AI가 계산하고 복붙용 텍스트를 만든다.

계산 금액 식은 https://github.com/joogrowth/yosulson/blob/main/배송/index.html 과 같게 한다. 코드의 요율이 바뀌면 코드가 우선이다.

복붙 문단의 틀은 이 문서 3항만 쓴다. `배송/index.html` 화면의 한 줄 일시 형식, `•배송 인건비`, 감가상각 문구는 쓰지 않는다.

**수고비는 넣지 않는다.** 구간 수고비·추가 수고비(적재, 외곽, 세팅 등) 모두 금지. `수고비합계`는 항상 0이다.

---

## 1. 받을 제원

가능하면 아래를 받는다. 비어 있으면 물어보거나, 있는 값만으로 계산하고 빠진 칸을 표시한다.

- 종류: `배송` / `배송세팅` / `출장` 중 하나
- 이름(담당·고객)
- 소속행사명(있으면)
- 날짜
- 장소(주소)
- 연락처(있으면, 여러 줄 가능)
- 품목(있으면)
- 출발 시각, 도착 시각, 행사 시간(있으면)
- 도착소요시간(분), 복귀소요시간(분) (왕복 이동 시간)
- 편도 km
- 편도 연료비(원)
- 통행료 편도(있으면)
- 주차비(있으면)

수고비 항목은 받지 않는다. 사용자가 말해도 견적·합계·시트에 넣지 않는다.

사용자가 "지난 실측"을 말하면, 같은 장소의 이전 확정 제원(거리·연료·통행료·시간)을 우선한다.

---

## 2. 계산

모든 금액은 원 단위. 표시는 천 단위 콤마.

### 기본값

- `왕복km` = 편도km × 2
- `총분` = 도착소요시간(분) + 복귀소요시간(분)
- `총시간문자` = `N시간` 또는 `N시간 M분`
- 시급 세 가지: 11000, 12000, 13000

### 인건비

각 시급마다

`인건비 = round(시급 × 총분 / 60)`

세 값을 ` / ` 로 이어 쓴다.

### 수고비

**넣지 않는다.** `수고비합계` = 0 고정.

복붙 문장에 수고비 줄을 만들지 않는다. 적재·외곽·세팅·기타 수고비 항목을 받지 않고, 말해도 무시한다.

### 차량 운영비

`차량운영비 = round(왕복km × 222)`

유류비와 별개다.

### 유류비

`유류비 = ceil((편도연료비 × 2) / 100) × 100`  (100원 단위 올림)

### 통행료·주차비

- 통행료가 있으면 `통행료 = 편도통행료 × 2`. 없으면 0원으로 적고 줄을 빼지 않는다.
- 주차비는 합계에 넣지 않는다. 문단 끝은 `주차비 별도`다. 금액이 있으면 `주차비 N원 (별도)`.

### 합계

`차량유지비 = 차량운영비 + 유류비 + 통행료`

각 시급마다

`합계 = 차량유지비 + 인건비`

주차비는 이 합계 밖이다. 주차비 제외 합계 열은 만들지 않는다.

## 3. 복붙용 답 형식

카톡에 바로 붙여 넣을 문단은 아래 틀만 쓴다. 줄 순서와 항목 이름을 바꾸지 않는다.

```text
[종류] 이름 / 행사명
일자: YY.MM.DD(요일)

출발: …
도착: …
행사시작: …

장소: …
담당자: 이름 (전화)
품목: …

--------------------------------

편도거리: Nkm (왕복 Nkm)
편도 연료비: …원
편도 통행료: …원
도착소요시간: … (N분)
복귀소요시간: … (N분)
총소요시간: N분 (…시간 …분)
•인건비 …원 / …원 / …원
(시급 11,000 / 12,000 / 13,000원 × N분)
•차량 운영비 …원
(왕복 Nkm × 222원/km, 유류비 제외)
•유류비 …원
(편도 …원 × 왕복 2)
•통행료 …원
•인건비 제외 차량유지비 …원
•합계 …원 / …원 / …원
(시급 11,000 / 12,000 / 13,000원 기준)
주차비 별도
```

날짜 표시: `YY.MM.DD(요일)` 예: `26.11.18(수)`

없는 연락처·품목만 빼도 된다. 거리, 연료비, 통행료, 소요시간, 인건비, 차량 운영비, 유류비, 통행료, 차량유지비, 합계, 주차비 별도는 남긴다.
수고비 줄은 만들지 않는다.

## 4. 배송견적 시트 저장 (화면·웹앱)

일상 저장은 **배송견적 화면**이 Apps Script 웹앱을 통해 구글시트 **배송견적**에 한다.
채팅 AI가 예전처럼 시트를 직접 고쳐 넣지 않는다. 사람이 화면에서 가안·최종저장을 한다.

시트는 이 파일 하나다. 사본이나 시험용 시트를 새로 만들지 않는다.
예전 **배송견적 기록** 시트(휴지통)는 쓰지 않는다.

- 화면: https://joogrowth.github.io/yosulson/배송/
- 웹앱(`/exec`): https://script.google.com/macros/s/AKfycbwK1uXP1m0CYyb9cxTiRcDIIQVh3LJcPkWvg45gUn-GBkf7u6j_GGp7lxbGmFRy7goguw/exec
- 시트: https://docs.google.com/spreadsheets/d/1gx7HTjwyCrIduf21Pj85z06210KlSxodWwnKr-SF2mg/edit
- 코드: `배송/index.html`, `배송/apps-script/`

### 시트 구조

- 연도 탭 `2026`, `2027` … : 그해 주문. 1행 묶음 이름, 2행 칸 이름, 3행부터 데이터
- `고객리스트` 탭: 이름 · 소속 · 연락처 · 메모
- `복기` 칸은 시트에서만 고른다 (`확정` / `보류` / `취소`). 화면·웹앱이 값을 지우지 않는다.
- 데이터 줄 높이는 한 줄로 둔다. `차량유지비(인건비 제외)` 칸은 이름·색으로 구분한다.

### 계정

- 관리자 아이디 `admin` 고정. 비밀번호는 화면 「관리자 등록」에서만 정한다. 문서·GitHub에 쓰지 않는다.
- 대표님은 「새 계정 만들기」로 등록한다.
- 스크립트 속성에 비밀번호를 미리 넣지 않는다.

### 웹앱 배포

코드를 고친 뒤 `clasp push` 하고, **기존 배포 ID를 새 버전으로 업데이트**한다.
`/exec` 주소가 바뀌면 `배송/index.html`의 `API_URL`도 같이 맞춰야 하므로, 주소를 바꾸지 않는 쪽을 우선한다.

## 5. 작업 규칙

1. 제원을 받으면 3항 틀로 계산해 답한다. 틀을 바꾸지 않는다.
2. 금액 식은 `배송/index.html` 과 같게 한다. 추측으로 요율을 바꾸지 않는다. 문단 모양은 3항이 우선이다.
3. 수고비는 넣지 않는다. 구간·추가 모두 금지.
4. 사용자가 빼 달라고 한 금액은 넣지 않는다.
5. 시트 저장은 배송견적 화면·웹앱이 한다. 채팅 AI가 예전 `배송견적 기록` 시트에 행을 넣지 않는다. 시트를 새로 만들지 않는다.
6. 견적 결과 문장·비밀번호는 GitHub에 올리지 않는다. 코드·지침·기억만 GitHub다.
7. 드라이브의 예전 "규정" 문서나 휴지통의 `배송견적 기록` 내용을 현재 규칙으로 쓰지 않는다.
8. 원스톱 연계(근퇴·급여와 자동 연결)는 설계하지 않는다. 견적만 한다.
9. **사용자가 정할 일을 AI가 먼저 판단·확정하지 않는다.** 선택지만 보여 주고, 사용자가 고른 뒤에 움직인다. 기본값을 임의로 정해 두고 진행하지 않는다. 의견은 사용자가 물을 때만 말한다. 만들기·고치기·저장 전에는 반드시 컨펌을 받는다.
10. 사용자를 팀장님으로 부른다. 질문은 한 번에 하나씩 하고, 어려운 말은 쓰지 않는다. 이해하지 못했다고 하면 그림이나 예시로 쉽게 다시 설명한다.

## 6. 빠른 확인 예

편도 21km, 편도 연료비 4158원, 도착소요시간 60분, 복귀소요시간 60분, 통행료·주차비 없음. 수고비 없음(항상).

- 왕복 42km
- 인건비(2시간): 22000 / 24000 / 26000
- 차량운영비: round(42×222)=9324
- 유류비: ceil(8316/100)×100=8400
- 차량유지비: 9324+8400=17724
- 합계: 39724 / 41724 / 43724
- 주차비 별도
