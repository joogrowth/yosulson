# 급여 기억

이 파일을 먼저 읽고 이어서 작업한다. 중요한 결정·운영 방식은 여기에 짧게 남긴다.

## 지금 쓰는 방식

- 급여 계산 코드는 이 GitHub 저장소에 없다.
- 전체 데이터를 취합해 엑셀(스프레드시트) 명세서로 만든다.
- 완성 파일은 드라이브 `요술손/급여` 아래에 둔다. (지금 10월은 `요술손/급여/급여/26년10월/`)
- GitHub `급여/` 는 폴더·명세서 위치를 안내하는 입구다.

## 꼭 지킬 것

- 개인 급여·비밀번호 같은 민감 정보는 GitHub에 올리지 않는다.
- 근퇴·배송·식자재와 자동 연결하는 원스톱은 만들지 않는다.
- 새 월 명세서를 만들면 드라이브에 두고, 필요하면 이 `기억.md`의 최근 명세서 링크를 갱신한다.
