식재료 시세 분석

식재료 가격을 기록하고 추세를 확인해서 가격 급등락에 미리 대응하는 도구

새 시세 기록 추가
가져오기 / 내보내기
JSON 파일로 백업하거나, scripts/fetch_kamis_prices.py 등으로 수집한 데이터를 붙여넣어 한 번에 가져올 수 있음
등록된 시세 기록
날짜품목분류가격출처메모
아직 등록된 시세 기록이 없음. 위에서 직접 입력하거나 샘플 데이터를 불러와서 시작할 수 있음
경고 기준 설정
직전 기록 대비 가격 변동률이 아래 기준을 넘으면 자동으로 등급이 표시됨
품목별 현황 (변동폭이 큰 순서)
품목당 2건 이상 기록이 있어야 변동률을 계산할 수 있음
품목별 시세 추이
선택한 품목의 기록이 없음
왜 데이터 출처가 필요한가
이 도구는 브라우저에서만 동작하는 오프라인 기록장이라 시세를 자동으로 긁어오지 않음(공공 API는 대부분 인증키가 필요하고, 브라우저에서 직접 호출하면 CORS로 막히는 경우가 많음). 대신 아래 공식 출처에서 API 인증키를 발급받아 scripts/fetch_kamis_prices.py 같은 스크립트로 주기적으로 데이터를 내려받은 뒤, 위 "가져오기" 기능으로 이 도구에 불러오는 방식을 권장함. data/sources.json 파일에도 동일한 목록이 정리되어 있어 다른 자동화 스크립트에서도 재사용 가능함.
