# yosulson

요술손케이터링 **식재료 시세 분석**과 운영 도구. 아이패드·폰·브라우저에서 `식재료시세분석/index.html`을 연다.

방향: 매달 시세 분석·PDF, 한 달 앞 제철. 고객 견적서·작업지시서는 구글시트에서 한 번 입력해 자동 기입(금액은 직원에게 숨김). 배송 견적은 차량·인건비 계산으로 별개다.

폴더:

```
yosulson/
  식재료시세분석/index.html  ← 식재료 시세 분석 = 월간 보고 · PDF
  시세/
    index.html            ← 검색·그래프·가져오기
    월간보고/index.html   ← 식재료시세분석으로 이동
    전망/index.html       ← 다음 달 제철
    data/                 ← 시세 JSON · 코드표
    scripts/              ← KAMIS/참가격 수집
    reports/              ← 저장한 PDF
  배송견적/index.html     ← 차량·인건비 (고객 견적서 아님)
  견적작업/index.html     ← 구글시트 견적서·작업지시서
```

## 도구 목록

### 1. `배송견적/index.html` — 배송 견적

배송/배송세팅/출장 유형별로 기본 정보, 거리, 시급 등을 입력하면 인건비·수고비·차량 운영비·유류비를 자동 계산해 결과를 텍스트로 복사할 수 있는 도구.

### 2. `시세/index.html` — 식재료 시세 분석 트래커

식재료 가격을 기록하고 추세를 확인해서 가격 급등락에 미리 대응하기 위한 도구.

### 3. `식재료시세분석/index.html` — 식재료 시세 분석 (월간 보고)

진입 화면이자 대표님 월간 동향 보고서. 채소·과일·곡물·축산·수산 합의 품목, 전월 대비 상승/하락/급등·범주별 표·미니 추이·인쇄(PDF). `시세/월간보고/`는 이 화면으로 보낸다. 숫자는 `시세/scripts/build_dashboard.py`가 `latest.json`으로 넣는다.

예전 `시세/월간보고`의 샘플 넣기·월 선택 도구는 별도 제품이 아니다. 보고 화면은 하나다.

- **시세 입력**: 품목명/카테고리/가격/단위/날짜/출처/메모를 입력해 기록을 쌓고, JSON 파일 또는 텍스트 붙여넣기로 가져오기/내보내기 가능. 브라우저 `localStorage`에 저장되므로 별도 서버가 필요 없음.
- **트렌드 대시보드**: 품목별 직전 대비 변동률을 계산해 급등/상승/보합/하락/급락 5단계로 배지 표시하고, 단계별 대처 제안 문구를 함께 보여줌. 경고 기준(%)은 직접 조정 가능. 품목을 선택하면 시세 추이를 꺾은선 차트로 확인 가능.
- **데이터 출처 안내**: 한국의 공식 식재료 시세 데이터 출처(KAMIS, 축산물유통정보, 수산물 위판 정보, 공공데이터포털 등)를 정리해 API 신청 방법과 인증 요구사항, 갱신 주기를 확인할 수 있음.

이 도구는 브라우저에서만 동작하는 오프라인 기록장이라 시세를 자동으로 긁어오지 않음(공공 API는 인증키가 필요하고, 브라우저에서 직접 호출하면 CORS로 막히는 경우가 많음). 대신 `시세/scripts/fetch_kamis_prices.py`처럼 서버/로컬 환경에서 실행하는 스크립트로 공식 API 데이터를 내려받은 뒤, "가져오기" 기능으로 불러오는 방식을 권장함.

## 데이터 수집 스크립트

`시세/scripts/fetch_kamis_prices.py`는 KAMIS Open API에서 기간별 시세 원자료를 내려받아 시세 화면이 바로 가져올 수 있는 JSON으로 변환하는 예시 스크립트. 사용하려면 KAMIS 회원가입 후 발급받은 인증키를 환경변수로 설정해야 함.

```bash
cd ~/yosulson/시세
export KAMIS_CERT_KEY="발급받은키"
export KAMIS_CERT_ID="발급받은아이디"
    python3 scripts/fetch_kamis_prices.py --days 30 --out data/kamis_latest.json
```

매달 월간 보고용으로 소매+가락도매+노량진경락을 한 번에 받으려면:

```bash
cd ~/yosulson/시세
python3 scripts/fetch_month.py --days 45 --out data/latest.json
```

받은 `시세/data/latest.json`을 시세 화면 데이터 관리에서 가져오면 월간 보고에 가락·노량진 실거래가 함께 반영된다. 당월에 거래가 없는 품목은 비워 두고, 지난 출하기 가격을 당월로 복사하지 않는다.

Python 표준 라이브러리만 사용하므로 별도 패키지 설치가 필요 없음(Python 3.8 이상 권장).

`시세/data/reference/kamis_품목_등급_코드표.xlsx`는 KAMIS 공식 품목/등급 코드표 원본(부류코드, 품목코드, 품종코드, 축산물 코드 등)이며, `fetch_kamis_prices.py`의 `LIVESTOCK_ITEMS` 목록을 채우거나 새 품목을 추가할 때 참고용으로 저장해 둠.
