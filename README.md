# 요술손케이터링 배송견적

메모를 붙이면 카톡·캘린더에 그대로 넣을 견적 문단을 만듭니다.

`index.html`을 브라우저에서 열면 됩니다. 견적 계산은 `quote.js`, 급여명세서는 `payroll.js`에 있습니다. `node --test quote.test.js payroll.test.js`로 확인합니다.

급여명세서는 출근, 배송 출발, 배송 복귀, 퇴근 네 시각으로 매장 근무와 배송 근무를 나눕니다. 직원은 두 구간을 합친 시간 전부 시급을 받고, 배송 견적과 비교하는 원가는 배송 구간의 인건비와 차량 실비뿐입니다.

확인된 출장 제원은 `data/trips.json`에 한 건씩 쌓습니다. 같은 일정을 고치면 그 행만 수정하고, 한 번의 실측으로 장소 통상 거리를 바꾸지 않습니다.

견적을 건넬 때는 문단 전체를 한 번에 복사하는 큰 버튼을 둔다. 받는 사람에게 전체 선택이나 길게 누르기를 시키지 않는다. 채팅 코드 블록의 작은 복사 아이콘은 손가락으로 누르기 어렵고 복사가 됐다 안 됐다 하므로 그 아이콘에 맡기지 않는다.
