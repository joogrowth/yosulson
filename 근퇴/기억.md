# 근퇴 기억

이 파일을 먼저 읽고 이어서 작업한다. 중요한 결정·운영 방식은 여기에 짧게 남긴다.

## 지금 쓰는 방식

- 직원이 단톡방 링크로 웹앱에 로그인해서 출근·퇴근한다.
- 기록은 구글 시트 **근무기록**에 쌓인다.
- GitHub `근퇴/apps-script/` 는 그 웹앱 소스 정본이다.
- `근퇴/index.html` 은 로그인 화면으로 바로 보낸다.

## 꼭 지킬 것

- 지금 쓰는 근무기록 시트를 복사하거나 이름만 바꿔 새 시트로 옮기지 않는다.
- 로그인 비밀번호·PIN은 GitHub·문서에 넣지 않는다. 시트 `로그인` 탭에만 둔다.
- 단톡방에 올린 로그인 주소를 함부로 바꾸지 않는다. 바꾸면 단톡·README·기억에 같이 반영한다.
- 근퇴를 배송·급여·식자재와 자동 연결하는 원스톱은 만들지 않는다.
